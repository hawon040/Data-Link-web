# 법적 검토 메모

> 변호사 검토가 아닌 기획 단계 정리. 수익화 전에 학교 창업지원단이나 무료 법률상담(대한법률구조공단 등)으로 점검받을 것.

## 1. 랜덤채팅 규제 (출시부터, 무료여도 적용)

여성가족부는 2020년 12월부터 익명 상대와 무작위 1:1로 연결하는 채팅 서비스 중
**실명·휴대전화 본인인증, 대화 저장, 신고 기능**을 갖추지 않은 곳을 청소년유해매체물로 보고
만 19세 미만 차단·유해표시 의무를 부과한다. ([뉴시스](https://mobile.newsis.com/view/NISX20201210_0001266032))

→ 이 서비스는 구조상 해당될 수 있다. 세 가지를 모두 갖춰 대상에서 벗어나는 방향으로 간다 (만 18세 신입생 포함).

- 학교 이메일만으로는 나이를 알 수 없다 (재수생·빠른년생·생일 전 1학년)
- 카카오 로그인의 출생연도는 사용자 입력값이라 성인 판단에 부적합 ([카카오 데브톡](https://devtalk.kakao.com/t/4-4/150561))
- 카카오 본사는 본인확인기관이 아님 (2023 기준). PASS·토스·카카오뱅크·은행 등이 지정 ([뉴시스](https://www.newsis.com/view/NISX20230413_0002265574))
- 통합 본인인증 중 PASS(통신사)만 연다. 카카오·네이버는 성별이 검증되지 않아 제외 (DECISIONS 2026-10-18)

## 2. 출시부터 적용

| 항목 | 할 일 |
| --- | --- |
| 개인정보보호법 | 처리방침 공개, 수집 동의, 카톡 ID를 상대에게 제공하는 것에 대한 별도 동의, 암호화·접근통제, 탈퇴 시 파기 |
| 학교 명칭·로고 | "백석대 공식"처럼 보이지 않게, 로고 사용 금지. 제휴 시 허락 |

## 3. 수익이 생기면

| 항목 | 내용 |
| --- | --- |
| 사업자등록 | 반복적 수익 발생 시 |
| 통신판매업 신고 | 유료 기능 판매 시. 직전년도 거래 50회 미만 또는 간이과세자는 신고 면제, 단 환불·청약철회 등 전자상거래법 의무는 유지 ([정리글](https://thecheck.co.kr/mail-order-business-report-exemption/)) |
| 부가통신사업 신고 | 채팅을 사업으로 제공 시. 소규모는 신고 간주 가능, 시행령 확인 ([아이뉴스24](https://www.inews24.com/view/1313798)) |
| 본인인증 계약 | 인증 대행사 계약에 사업자등록이 필요할 수 있음 (포트원 문의) |

## 4. 수익 모델

- 권장: 무료 + 교내 카페·식당 제휴 쿠폰·광고
- 비권장: "돈 내면 이성과 매칭" 같은 성별 기반 유료 기능
- 금지: 사용자 데이터 판매·외부 제공
