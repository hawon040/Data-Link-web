# 화면·기능 점검 (2026-10-19)

모든 화면의 버튼·링크·데이터 읽기/쓰기를 코드와 Supabase(실제 DB)에서 확인한 결과.
✅ DB와 연결되어 동작 · 🔧 이번에 고침 · ⚠️ 동작하지만 한계 있음 · ❌ 연결 안 됨/없음

## 화면별

### 가입 (01·02·13·42·33·14·03·09·15·32)
- ✅ 학교 메일 코드 발송·확인 (Supabase Auth OTP)
- ✅ 약관 동의 체크 → 가입 메타데이터 → 본인인증 후 `profiles.terms_agreed_at`
- ❌ 휴대폰 본인인증(33): 포트원 키가 없어 "준비 중" 안내만 나옴 → **신규 가입이 여기서 막힘**
- ⚠️ 인증 코드(13) 3분 타이머는 화면 표시용. 실제 만료는 Supabase Auth의 OTP 만료 설정을 따름
- ✅ 프로필 만들기(09), 카카오톡 ID 등록(15) → `profiles`, `set_my_kakao_id`
- ✅ 만 19세 미만(03), 탈퇴 계정(withdrawn) 안내 후 로그아웃

### 홈·매칭 (04·16·34·43·39·17·35·36·18·10·38)
- ✅ 내일 매칭 신청/취소 토글 → `apply_match` / `cancel_match`
- ✅ 만남 목적·조건(같은 성별·같은 학과·학년) 저장, 신청 후 바꾸면 다시 신청
- ✅ 이번 주 친구가 된 쌍 수 → `public_stats` (실제 교환 성사 수)
- ✅ 매칭 없음(10): 전날 짝이 없던 사람만 (`was_leftover_today`), 다음날 우선 매칭
- ❌ 정오 매칭 발표 알림 없음 (앱에 들어와야 알 수 있음)

### 대화 (05·06·19·21·22·40·31·23·37)
- ✅ 실시간 채팅 (Realtime), 메시지 20개·24시간 제한과 연락처 가림은 DB 트리거
- ✅ 대화 주제 카드 → 첫 메시지 전송
- ✅ 신고 → `reports`, 서로 다른 3명 신고 시 자동 정지
- 🔧 차단 실패 시 안내 문구 (이전엔 실패해도 홈으로 이동)
- ⚠️ 대화 주제 질문 3개는 코드에 고정
- ❌ 신고를 처리할 운영자 화면 없음 → 정지 해제·제재는 SQL로만 가능

### 교환·후기 (07·24·25·26·11·41·12·30)
- ✅ 교환 선택 → `choose_exchange`, 둘 다 동의 시 `get_partner_contact`
- 🔧 상대가 거절하거나 24시간 안에 고르지 않으면 "기다리는 중"에 멈추던 문제 → `my_exchange_state`로 종료 처리, 대기 화면 30초마다 갱신
- 🔧 "교환하지 않고 마치기" 실패 시 안내 문구
- 🔧 교환 성사(11) 화면에 상대 프로필 사진 표시
- ✅ 후기 저장 → `reviews`
- ⚠️ 후기는 저장만 되고 매칭·통계 어디에도 쓰이지 않음
- ⚠️ "ID가 본인 것이 아니었어요 · 7일 내 신고 가능" 문구의 7일 제한은 DB에서 강제하지 않음

### 내 정보 (08·27·44·45·28·29 + 신고 내역·탈퇴)
- 🔧 프로필 사진 업로드·변경·삭제 (본인 + 교환 성사 상대만 볼 수 있음)
- ✅ 매일 자동 참여·같은 성별만 토글, 저장 실패 시 되돌림
- ✅ 프로필·닉네임·카카오톡 ID 수정 (실제로 바뀐 행까지 확인)
- 🔧 개인정보(29): 등록된 카카오톡 ID, 신고 내역 건수, 정지 안내를 DB에서 읽음
- 🔧 신고 내역 화면 (`my_reports`)
- ✅ 차단 목록 (`my_blocks`) — 한 번 만난 사람은 다시 매칭되지 않으므로 차단 해제 기능은 두지 않음
- ✅ 로그아웃, 회원 탈퇴(사진 파일 삭제 → `withdraw_account`), 약관·처리방침 링크

## 아직 없는 기능 (우선순위 순)

1. 휴대폰 본인인증 연동 (포트원) — 가입 완료의 전제
2. 운영자 화면: 신고 목록·대화 기록 확인, 정지/해제, 부적절한 프로필 사진 삭제
3. 정오 매칭 발표 알림 (메일 또는 웹 푸시)
4. 신고 사유에 "부적절한 프로필 사진" 추가 (사진 기능이 생겨서 필요)
5. 문의 창구 (카카오톡 채널·메일) 와 공지
6. 홈 화면 아이콘 (`manifest.webmanifest` icons 비어 있음)
7. 정식 메일 발송 서비스 (지금은 Gmail SMTP)
